# Коч Старс — онлайн
1. Залей папку на GitHub (или загрузи в Render/Railway).
2. Render → New Web Service → Build: `npm install` → Start: `npm start`.
3. Открой выданную ссылку на телефонах: 🌐 Онлайн → Создать комнату → друзья вводят код → СТАРТ.
Локально: `npm install && npm start`, затем http://localhost:3000
